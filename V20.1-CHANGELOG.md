# XE3AGLE v20.1 change log

- Versioned the project as 20.1.0 and retained the v20 UI, styling, branding, icons, and existing modules as the starting point.
- Added pure analytics statistics and expectancy modules to satisfy the previously missing test imports.
- Updated the migration test to assert the current schema version (19) while retaining checks for v16 data containers.
- Reworked offline queue behavior to retain user-scoped snapshots and only remove an item after an explicitly payload-aware sync handler confirms success. If no such handler is configured, queued edits are retained instead of being falsely reported as synced.
- Added free-first setup, provider-configuration, and production safety documentation.

## Known integration requirements

The project still requires real provider credentials and deployment-level acceptance testing for Google OAuth, transactional email, object storage, database connection, session/device revocation, and monitoring. No paid billing/subscription features are included.
