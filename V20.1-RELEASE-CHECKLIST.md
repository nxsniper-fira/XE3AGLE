# XE3AGLE v20.1 release acceptance checklist

## Local automated checks
- [ ] `npm test` passes
- [ ] `npm run check` passes
- [ ] Backend `npm run check` passes

## Required live acceptance tests before public launch
- [ ] Email signup, verification, login, logout, reset password, and expired session behavior
- [ ] Google OAuth using configured authorized origins and redirect URIs
- [ ] Confirm every API route denies unauthenticated access and cross-user data access
- [ ] Register two devices, revoke one remotely, confirm revoked token/session is rejected
- [ ] Database migration, backup, restore to a clean database, and deletion/cascade behavior
- [ ] Upload, view, download, and delete private media from two devices; verify ownership and size/type limits
- [ ] Offline edits replay exact queued payloads, handle conflict, retry safely, and survive reload/re-login
- [ ] Full trading lifecycle, limits, DST/session boundaries, active trade across midnight, and journal correctness
- [ ] CSV/XLSX/JSON export and import validation/rollback
- [ ] Mobile browser layout, PWA install/update, service worker cache invalidation
- [ ] Health endpoint, error reporting, uptime/backup monitoring, and restore runbook

Do not mark a checkbox complete without executing and recording the result in the target environment.
